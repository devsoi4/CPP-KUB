# Tabbed UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn CppLearn into a VS Code–style multi-file editor (document tabs, Explorer sidebar, bottom panel, shared theme).

**Architecture:** `MainWindow` stops owning a single `CodeEditor`; it owns a `DocumentTabs` widget whose items are `Document` objects (editor + path + preset). Problems list moves into `ConsoleWidget` as a bottom-panel tab. `win.editor/path/problems` stay as delegating properties so existing tests keep working.

**Tech Stack:** Python 3.10+, PySide6-Essentials (incl. QtSvg), pytest (offscreen Qt, `QT_QPA_PLATFORM=offscreen`).

**Spec:** `docs/superpowers/specs/2026-11-04-tabbed-ui-design.md`

## Global Constraints

- All UI text in Thai; no new dependencies beyond PySide6-Essentials; works offline.
- Thai input/print/PDF behaviour and `tests/test_gui.py`, `tests/test_runner.py`, `tests/test_errors_th.py` keep passing (tests need `g++`; run `python -m pytest tests -q`).
- No concurrent runs; F5 runs the active tab; default theme light.
- Session restore saves only saved-file paths (+ active one); untitled content is not restored.
- Untitled tab names: `ไม่มีชื่อ-N`.

## Review Focus

- Closing a tab while its program is running must stop the runner without crashing.
- A run that finishes after its tab was closed must not crash (`_run_doc` is None).
- The same file opened via different spellings (relative, different case on Windows) activates the existing tab.
- Closing the last tab leaves one fresh untitled tab (never zero tabs).
- Session restore skips paths that no longer exist and Explorer clicking a deleted file shows a warning, not a traceback.

## File Structure

- Create `app/theme.py` — palette tokens + Qt stylesheet.
- Create `app/icons.py` — inline-SVG icons recoloured per theme.
- Create `app/document.py` — `Document` (editor, path, preset, untitled number).
- Create `app/tabs.py` — `DocumentTabs` (QTabWidget with close/modified/running markers).
- Create `app/sidebar.py` — `ActivityBar` + `Explorer`.
- Modify `app/console.py` — add problems tab, preset get/set.
- Modify `app/main_window.py` — orchestration on top of the above.
- Modify `app/editor.py` — expose cursor position signal use (none new; `cursorPositionChanged` already exists).
- Tests: `tests/test_theme_icons.py`, `tests/test_tabs.py`, `tests/test_gui.py` (extend).
