# CPP-KUB — โปรแกรมเขียน C++ สำหรับการสอน

โปรแกรมเดสก์ท็อป (Python + PySide6) สำหรับสอนภาษา C++ ในห้องเรียน
ใช้งานออฟไลน์ได้ทั้งหมด พิมพ์และแสดงผลภาษาไทยได้ และอธิบาย error ของ g++ เป็นภาษาไทย

## ฟีเจอร์ในเวอร์ชันนี้ (MVP)

- **เปิดหลายไฟล์เป็นแท็บ แบบ VS Code**: ปุ่มปิด ×, จุด ● เมื่อยังไม่บันทึก, ลากเรียงแท็บ, คลิกกลางเพื่อปิด, Ctrl+W ปิดแท็บ, Ctrl+Tab / Ctrl+Shift+Tab สลับแท็บ, Ctrl+N แท็บใหม่ (เปิดไฟล์เดิมซ้ำจะกระโดดไปแท็บเดิม)
- **แถบข้าง Explorer** (Ctrl+B แสดง/ซ่อน): ไฟล์ที่เปิดอยู่, ตัวอย่างโค้ด 10 ตัวอย่าง, และโฟลเดอร์งานที่เลือก — คลิกเพื่อเปิดเป็นแท็บ
- **ตัวช่วยมองเห็นการทำงาน (Visualizer)**: ดีบักทีละบรรทัด (F9/F10/F11), ดูตัวแปร, call stack, รอบของ loop และภาพ array/pointer — ดูหัวข้อด้านล่าง
- แผงล่างรวม **ผลลัพธ์ / ปัญหา (จำนวน) / ข้อมูลนำเข้าล่วงหน้า** — ข้อมูลนำเข้าล่วงหน้าแยกตามแท็บ
- จำแท็บที่เปิดค้างไว้ (เฉพาะไฟล์ที่บันทึกแล้ว) และเปิดกลับมาให้เมื่อเปิดโปรแกรมครั้งหน้า
- ธีมสว่าง/มืดที่ออกแบบเป็นชุดเดียวกัน (เมนู มุมมอง) แถบสถานะแสดงบรรทัด/คอลัมน์และ encoding
- ตัวแก้ไขโค้ด: เลขบรรทัด, ไฮไลต์สี, ย่อหน้าอัตโนมัติ, ปิดวงเล็บ/เครื่องหมายคำพูดอัตโนมัติ, ขยาย/ลดตัวอักษร (Ctrl + / Ctrl -), ธีมมืด
- ปุ่ม **รัน (F5)** คอมไพล์แล้วรันทันที, **หยุด (Shift+F5)**
- หน้าต่างผลลัพธ์ + ช่อง "ป้อนข้อมูล" สำหรับ `cin` (พิมพ์ภาษาไทยได้) + ปุ่ม EOF
- แท็บ **ข้อมูลนำเข้าล่วงหน้า** ใส่ input ไว้ก่อน ทดสอบซ้ำได้โดยไม่ต้องพิมพ์ใหม่ทุกรอบ
- **แปล error/warning ของ g++ เป็นภาษาไทย** + ไฮไลต์บรรทัดที่ผิด + แผง "ปัญหาที่พบ" คลิกแล้วกระโดดไปบรรทัดนั้น
- แปลสาเหตุที่โปรแกรมพัง (segfault, หารศูนย์, stack overflow) เป็นภาษาไทย
- กันโปรแกรมวนไม่รู้จบ: หยุดเองเมื่อไม่มีความเคลื่อนไหวเกิน 15 วินาที หรือพิมพ์ข้อความเกิน 200,000 ตัวอักษร
- ตัวอย่างโค้ด 10 ตัวอย่าง (เมนู "ตัวอย่างโค้ด") รวมตัวอย่างที่มี error ไว้ฝึกอ่านข้อผิดพลาด
- **พิมพ์โค้ด / พิมพ์ผลลัพธ์ / ส่งออก PDF** (ภาษาไทยแสดงถูกต้อง, มีเลขบรรทัด)
- เปิดไฟล์เก่าที่บันทึกเป็น TIS-620/cp874 ได้ และบันทึกใหม่เป็น UTF-8 ให้อัตโนมัติ
- วางโค้ดจาก Word/เว็บ: แปลงเครื่องหมายคำพูดโค้ง “ ” ให้เป็น " อัตโนมัติ (ต้นเหตุ error ที่นักเรียนเจอบ่อย)

## วิธีรันระหว่างพัฒนา

```
pip install -r requirements.txt
python main.py
```

ต้องมี `g++` ให้โปรแกรมเรียกใช้ได้ (ตัวที่วางไว้ใน `compiler\bin\g++.exe` ข้างโปรแกรมจะถูกใช้ก่อน
ถ้าไม่มีจะหาใน PATH)

## ตัวช่วยมองเห็นการทำงาน (Visualizer)

กด **F9** (เมนู "ดีบัก") เพื่อเดินโปรแกรมทีละบรรทัด — แผงด้านขวาจะแสดง:

- **ตารางตัวแปร** ค่าเปลี่ยนแล้วไฮไลต์สี, array/struct แตกเป็นช่อง
- **Call stack** (เหมาะกับสอน recursion) คลิกเฟรมเพื่อดูตัวแปรและบรรทัดของเฟรมนั้น
- **ป้ายรอบ loop** เช่น `วนรอบที่ 2 · i = 1`
- **ภาพหน่วยความจำ** array เป็นช่องพร้อมเลข index, pointer เป็นลูกศรชี้ไปที่ตัวแปร (หรือกล่อง heap)

| ปุ่ม | ทำอะไร |
|---|---|
| F9 | เริ่มดีบัก |
| F10 | ข้ามบรรทัด (ไม่เข้าไปในฟังก์ชัน) |
| F11 | เข้าฟังก์ชัน |
| Shift+F11 | ออกจากฟังก์ชัน |
| F8 | ทำต่อจนจบโปรแกรม |
| Shift+F5 | หยุดดีบัก |

ข้อมูลนำเข้าสำหรับ `cin` ใช้จากแท็บ "ข้อมูลนำเข้าล่วงหน้า" (ยังพิมพ์สดระหว่างดีบักไม่ได้)

**ต้องมี `gdb.exe`**: วางไว้ใน `compiler\bin` ข้าง `g++.exe` (MinGW-w64 / WinLibs แบบเต็มมี gdb ให้
ต้องคัดลอก DLL และโฟลเดอร์ `lib` ที่ gdb ใช้มาด้วย เช่น `libpython3.x.dll`) ถ้าไม่มี ปุ่มดีบักจะแจ้งเป็นข้อความภาษาไทย
ส่วนการรันปกติ (F5) ใช้ได้เหมือนเดิม

## ทำเป็นโปรแกรมแจกจ่ายบน Windows

1. ดาวน์โหลด MinGW-w64 แบบ zip (เช่นจาก WinLibs หรือ MSYS2) แตกไฟล์ไว้ในโฟลเดอร์ `compiler`
   ของโปรเจกต์นี้ ให้ได้พาธ `compiler\bin\g++.exe`
2. ดับเบิลคลิก `build_windows.bat` (ต้องติดตั้ง Python 3.10+ บนเครื่องที่ใช้สร้าง)
3. ได้โฟลเดอร์ `dist\CPP-KUB\` — แจกทั้งโฟลเดอร์ (zip / USB) นักเรียนดับเบิลคลิก `CPP-KUB.exe`
   ได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม และไม่ต้องมีสิทธิ์ admin

เคล็ดลับ: ถ้า antivirus ของโรงเรียนแจ้งเตือนผิดพลาด ให้ขอให้ฝ่าย IT อนุญาตทั้งโฟลเดอร์ `CPP-KUB`

## เรื่องภาษาไทยที่ออกแบบไว้

| เรื่อง | วิธีจัดการ |
|---|---|
| พิมพ์โค้ด/ข้อความไทย | ทุกอย่างเป็น Unicode (UTF-8) การปิดวงเล็บอัตโนมัติทำงานเฉพาะอักขระ ASCII จึงไม่รบกวนการพิมพ์ไทย |
| `cout << "สวัสดี"` | คอมไพล์ด้วย `-finput-charset=UTF-8 -fexec-charset=UTF-8` ส่งผลลัพธ์ผ่าน pipe แล้วถอดรหัส UTF-8 (ไม่พึ่งโค้ดเพจของ console) |
| `cin >> ชื่อ` ภาษาไทย | ส่ง input เป็น UTF-8 เข้า stdin |
| ชื่อผู้ใช้/โฟลเดอร์ภาษาไทย | ไฟล์คอมไพล์ทั้งหมดอยู่ในโฟลเดอร์ ASCII (`work` ข้างโปรแกรม หรือ `C:\Users\Public\CPP-KUB`) เพราะ MinGW บางรุ่นเปิดพาธไทยไม่ได้ |
| ข้อความถามก่อนรับ input | ใส่ prelude ให้ stdout ไม่ถูก buffer จึงเห็นข้อความถามทันที |
| ฟอนต์ | เลือกฟอนต์โค้ดที่มีในเครื่อง แล้วตามด้วย Leelawadee UI / Tahoma / Noto Sans Thai เพื่อแสดงอักษรไทย |
| `string::size()` | เก็บแบบ UTF-8 อักษรไทย 1 ตัว = 3 ไบต์ (มีตัวอย่างข้อ 09 ใช้สอนเรื่องนี้) |

## โครงสร้าง

```
main.py                 จุดเริ่มโปรแกรม
app/compiler.py         คอมไพล์/รัน/timeout/อ่านเขียน stdin (QProcess)
app/errors_th.py        กฎแปล error ของ g++ เป็นไทย (เพิ่มกฎได้ที่ RULES)
app/editor.py           ตัวแก้ไขโค้ด + ไฮไลต์
app/console.py          แผงล่าง: ผลลัพธ์ + ช่องป้อนข้อมูล + รายการปัญหา + ข้อมูลล่วงหน้า
app/document.py         เอกสารหนึ่งแท็บ (editor + พาธ + ข้อมูลล่วงหน้า)
app/tabs.py             แท็บเอกสาร (ปุ่มปิด, ● ยังไม่บันทึก, ▶ กำลังรัน)
app/sidebar.py          แถบไอคอนซ้าย + Explorer
app/theme.py            ชุดสีธีมสว่าง/มืด + Qt stylesheet
app/icons.py            ไอคอน SVG ในโค้ด
app/main_window.py      หน้าต่างหลัก เมนู ไฟล์ พิมพ์ รัน
app/printing.py         พิมพ์/ส่งออก PDF
app/textio.py           อ่านเขียนไฟล์ (UTF-8 / cp874)
app/examples.py         โค้ดตัวอย่าง
app/visualizer/         ตัวช่วยมองเห็นการทำงาน: gdbmi (อ่านผล gdb), model, session (คุม gdb), loops,
                        memory_view (ภาพหน่วยความจำ), panel (แผงด้านขวา)
tests/                  ชุดทดสอบ (pytest)
```

เพิ่มกฎแปล error: เติมคู่ `(regex, คำอธิบายไทย)` ใน `RULES` ของ `app/errors_th.py`
กฎที่เฉพาะเจาะจงต้องอยู่ก่อนกฎกว้าง (ใช้กฎแรกที่ตรง) ใช้ `{1}` `{2}` แทนกลุ่มที่จับได้ และ `{prev}` แทน "บรรทัดก่อนหน้า"

## ทดสอบ

```
pip install pytest
python -m pytest tests -q
```

ชุดทดสอบคอมไพล์และรันด้วย g++ จริง ตรวจการรับ-ส่งภาษาไทย, error ไทย, timeout, การพังของโปรแกรม, การอ่านไฟล์ cp874 และการส่งออก PDF

## ข้อจำกัดที่ควรรู้

- เวอร์ชันนี้ทดสอบบน Linux เท่านั้น ส่วนที่เฉพาะ Windows (การแพ็ก MinGW, `CREATE_NO_WINDOW`, การ build ด้วย PyInstaller, ฟอนต์ Windows) ยังไม่ได้ทดสอบ แนะนำให้ลองบนเครื่องจริง 1 เครื่องก่อนแจกทั้งห้อง
- ยังไม่มีระบบโจทย์ตรวจอัตโนมัติ (อยู่ในแผนเฟสถัดไป) และ Visualizer ยังพิมพ์ `cin` สดระหว่างดีบักไม่ได้
- ยังไม่ได้ทดสอบการพิมพ์ออกเครื่องพิมพ์จริง (ทดสอบเฉพาะส่งออก PDF)
- กฎแปล error ครอบคลุมข้อผิดพลาดที่พบบ่อยของมือใหม่ ข้อความที่ไม่มีกฎจะแสดงคำอธิบายทั่วไปพร้อมข้อความ g++ เดิม
